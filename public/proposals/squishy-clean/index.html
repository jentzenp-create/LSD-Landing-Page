You don't have to pick between fun and premium.

Both current versions get half of it right. The colorful one pops on camera, but its icon row reads "dollar store." The sophisticated one feels expensive, but it disappears in a TikTok. The refresh lands in between.

Keep

The purple liquid and the iridescent bubbles. Both read as premium on camera. The front gets a simpler, bolder layout so the name and gummy character carry across a phone screen.

Change

The icon row. "Toy safe," "gentle foam" and "removes dust and dirt" stay, rebuilt as one clean icon set instead of clip-art badges. The border gets tested both ways, with and without, so you can pick on the real bottle.

Lock

Compliance. "Squishy Clean" on the bottle, never NeeDohs. Scent wording like "yummy gummy" if required. Back panel set from your compliance copy and the printer's exact specs once they land Thursday.
